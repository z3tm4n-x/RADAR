# Техническое задание RADAR

## 1. Назначение

RADAR предназначена для инженерного расчета радиационных условий на борту космического аппарата и подготовки расчетных требований по радиационной стойкости БРЭА.

## 2. Базовый профиль

Профиль по умолчанию: ОСТ 134-1044-2007.

Обновленные модели СКЛ и ГКЛ по ГОСТ Р могут подключаться только явно через отдельный профиль методики.

## 3. Зафиксированные решения первой версии

- САС задается только целым числом лет.
- Дробный САС не поддерживается.
- Доза выводится в рад.
- Экспорт требований выполняется только в XLSX.
- Графики в XLSX-файл требований не добавляются.
- Защита по умолчанию: сферическая алюминиевая.
- Набор защит по умолчанию: 0.01; 0.1; 0.3; 0.5; 1.0; 1.5; 2.0; 3.0; 10.0 г/см².
- Kp по умолчанию: 3.
- Электроны ГКЛ в первой версии не рассчитываются.
- Тормозное излучение электронов ЕРПЗ учитывается.
- Протоны входят в LET/ЛПЭ-расчет для SEE.
- SEE рассчитывается по методике исходного прототипа RADAR.

## 4. Основной расчетный pipeline

1. Проверка входных данных.
2. Формирование ряда солнечной активности.
3. Расчет орбитальной трассы.
4. Расчет геомагнитных координат.
5. Расчет функции проникновения СКЛ и ГКЛ.
6. Расчет внешних спектров СКЛ.
7. Расчет внешних спектров ГКЛ.
8. Расчет спектров ЕРПЗ на орбите.
9. Расчет спектров СКЛ и ГКЛ на орбите после геомагнитного отсечения.
10. Расчет прохождения частиц через сферическую алюминиевую защиту.
11. Расчет спектров за защитой.
12. Расчет LET/ЛПЭ-спектров ТЗЧ.
13. Расчет LET/ЛПЭ-вклада протонов.
14. Расчет суммарного LET/ЛПЭ-спектра для SEE.
15. Расчет доз.
16. Расчет тормозного излучения электронов ЕРПЗ.
17. Расчет SEE.
18. Формирование таблиц.
19. Экспорт XLSX.

## 5. Валидация

Контрольные расчеты на ГСО используются как ориентир.

100% совпадение не требуется. Результаты должны быть сопоставимыми по порядку величины и не должны отличаться на порядок и более без объяснимой причины.

Контрольные расчеты не являются абсолютным эталоном и могут содержать собственные ошибки.

## 6. Экспорт XLSX

Файл требований должен содержать таблицы:

1. Методика;
2. Исходные данные;
3. Солнечная активность;
4. Защиты;
5. Доза от защиты;
6. Протоны СКЛ — флюенс за САС;
7. Протоны ГКЛ — флюенс за САС;
8. Протоны ЕРПЗ — флюенс за САС;
9. Протоны — суммарный флюенс за САС;
10. Электроны ЕРПЗ — флюенс за САС;
11. LET ТЗЧ СКЛ;
12. LET ТЗЧ ГКЛ;
13. LET протоны СКЛ;
14. LET протоны ГКЛ;
15. LET протоны ЕРПЗ;
16. LET суммарный для SEE;
17. SEE по защитам;
18. Версии моделей;
19. Допущения;
20. Лог расчета.
