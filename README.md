# RADAR

RADAR — Radiation Analysis and Design Assessment Resource.

Программа предназначена для инженерного расчета радиационных условий на борту космического аппарата и подготовки расчетных требований по радиационной стойкости бортовой радиоэлектронной аппаратуры.

## Базовые методические решения

- Профиль по умолчанию: ОСТ 134-1044-2007.
- САС: только целое число лет.
- Единица дозы: рад.
- Геомагнитный индекс по умолчанию: Kp = 3.
- Защита по умолчанию: сферическая алюминиевая защита.
- Электроны ГКЛ в первой версии не рассчитываются.
- Тормозное излучение электронов ЕРПЗ учитывается.
- Протоны входят в LET/ЛПЭ-расчет для SEE.
- Экспорт требований: XLSX.
- Графики в XLSX-файл требований не добавляются.

## Статус

Проект находится на этапе формирования архитектуры и расчетного ядра.
